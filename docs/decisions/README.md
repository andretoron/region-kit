# Keputusan Arsitektur

Bagian ini mencatat keputusan proyek yang penting, sulit dibalik, atau berdampak
pada public API dan batas package.

## Dokumen

- [Fondasi proyek](./project-foundation.md)

ADR baru menggunakan nomor berurutan dan nama file `NNNN-judul-keputusan.md`.
Setiap ADR sekurangnya menjelaskan status, konteks, keputusan, dan konsekuensinya.
Perubahan kecil yang tidak memiliki trade-off arsitektural tidak memerlukan ADR.
