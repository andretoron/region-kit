arsitektur `region-kit`.

- [Panduan](./guides/README.md) — langkah penggunaan berdasarkan tugas.
- [Referensi](./reference/README.md) — referensi API dan kontrak teknis.
- [Keputusan](./decisions/README.md) — fondasi proyek dan Architecture Decision
